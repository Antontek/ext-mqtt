# MQTT

WiFi で MQTT ブローカーに接続し、O Bricks の Web ページのダッシュボードやほかのデバイスとデータをやり取りします。データの形式は「トピック＋データ」で、データは JSON です（例：`35`、`[0.5, -0.2]`、`"hello"`）。ダッシュボードと同じ形式です。

WiFi 付きのハブが必要です（Raspberry Pi Pico W、Pico 2 W など）。

## ダッシュボードと組み合わせる

1. ハブのプログラム：まず「**WiFi に接続**」、次に「**MQTT ブローカーに接続**」を置きます（既定は `broker.hivemq.com` で、ダッシュボードの既定と同じです）。
2. ダッシュボード：タブバー右側の「**接続**」を押し、既定の HiveMQ のまま接続します。
3. 両方の**接頭辞を同じに**します（両方とも空欄でもかまいません）。
4. ダッシュボードの操作ウィジェット（ジョイスティック、スライダー、ボタン、スイッチ）が送るトピックは、ハブで「**MQTT トピック … の数値**」「**MQTT トピック … に新しいデータがある？**」で読みます。ハブが「**MQTT 送信**」で送ったデータは、ダッシュボードの数値表示や折れ線グラフで受け取れます。

| ダッシュボードのウィジェット | 送るデータ | ハブでの読み方 |
|---|---|---|
| スライダー | 数値（例：`70`） | MQTT トピック robot/speed の数値 1 番目 |
| ジョイスティック | `[x, y]`、-1～1 | x が 1 番目、y が 2 番目 |
| ボタン | 押すと `1`、離すと `0` | MQTT トピック robot/stop に新しいデータがある？ |
| スイッチ | オンで `1`、オフで `0` | MQTT トピック robot/led の数値 1 番目 |

## ブロック

- **WiFi に接続 名前 … パスワード …**：最大 15 秒待ち、IP をコンソールに表示します。
- **MQTT ブローカーに接続 … 接頭辞 …**：接頭辞は任意です。切断されると自動で再接続します。
- **MQTT 送信 トピック … データ …**：数値、文字、はい／いいえを送れます。
- **MQTT トピック … に新しいデータがある？**：新しいデータが届くと 1 回だけ「はい」になります。「もし」と組み合わせて使います。
- **MQTT トピック … の数値 … 番目**：最後に受け取った数値。データに数値が複数あるときは何番目かを選びます。まだ届いていないときは 0。
- **MQTT トピック … の最新データ**：最後に受け取ったデータ（数値、文字、リスト）。まだ届いていないときは None。

プログラムが使うライブラリ（`obricks_mqtt.py`、`mqtt_simple.py`）は、プログラムを実行・ダウンロードするときにハブのプロジェクトフォルダーの `lib/` へ自動で書き込まれます。自分でコピーする必要はありません。

データを読むブロックは実行のたびに受信したメッセージも処理するので、「ずっと繰り返す」の中に置くだけで使えます。受信用のプログラムを別に書く必要はなく、初めて読むトピックは自動で購読します。

## 注意

- **WiFi のパスワードはプログラムに書き込まれます**：プロジェクトやサンプルを共有する前に消してください。
- **公開ブローカーはみんなで共有しています**：送ったデータを誰でも見られ、データを送り込むこともできるので、機密データは送らないでください。ほかの人とトピックがぶつからないように接頭辞（例：`myclass/team1`）を付け、ダッシュボードにも同じ接頭辞を設定できます。
- ハブは MQTT の TCP 1883 で接続します（ダッシュボードはブラウザー内で WebSocket を使います）。同じブローカーに接続するので、やり取りできます。
- ファームウェアに `umqtt.simple` があればそれを使い、なければこの拡張に同梱されたもの（micropython-lib の umqtt.simple、MIT ライセンス）を使います。
