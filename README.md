# MQTT

用 WiFi 連上 MQTT broker，和 O Bricks 網頁的儀表板、或其他設備互傳資料。資料的格式是「主題＋資料」，資料是 JSON（例如 `35`、`[0.5, -0.2]`、`"hello"`），和儀表板一樣。

主機要有 WiFi，例如 Raspberry Pi Pico W、Pico 2 W。

## 搭配儀表板

1. 主機的程式：先放「**連上 WiFi**」，再放「**連上 MQTT broker**」（預設是 `broker.hivemq.com`，和儀表板的預設一樣）。
2. 儀表板：按分頁列右邊的「**連線**」，broker 用預設的 HiveMQ，按連線。
3. 兩邊的**前綴要一樣**（都不填也可以）。
4. 儀表板的控制元件（搖桿、滑桿、按鈕、開關）送出的主題，主機用「**MQTT 主題 … 的數字**」、「**MQTT 主題 … 有新資料？**」讀；主機用「**MQTT 送出**」送的資料，儀表板的數值顯示、折線圖就收得到。

| 儀表板元件 | 送出的資料 | 主機這樣讀 |
|---|---|---|
| 滑桿 | 數字，例如 `70` | MQTT 主題 robot/speed 的數字 第 1 個 |
| 搖桿 | `[x, y]`，-1～1 | x 是第 1 個、y 是第 2 個 |
| 按鈕 | 按下 `1`、放開 `0` | MQTT 主題 robot/stop 有新資料？ |
| 開關 | 打開 `1`、關掉 `0` | MQTT 主題 robot/led 的數字 第 1 個 |

## 積木

- **連上 WiFi 名稱 … 密碼 …**：最多等 15 秒，在主控台印出 IP。
- **連上 MQTT broker … 前綴 …**：前綴選填。斷線時會自己重連。
- **MQTT 送出 主題 … 資料 …**：數字、文字、是／否都可以。
- **MQTT 主題 … 有新資料？**：收到新資料時是「是」一次，放進「如果」用。
- **MQTT 主題 … 的數字 第 … 個**：最後收到的數字；資料有好幾個數字時拿第幾個。還沒收到時是 0。
- **MQTT 主題 … 最新的資料**：最後收到的資料（數字、文字或清單），還沒收到是 None。

程式用到的函式庫（`obricks_mqtt.py`、`mqtt_simple.py`）會在執行、下載程式時自動寫到主機上專案資料夾的 `lib/`，不用自己複製。

讀資料的積木每次執行時會順便處理收到的訊息，放在「重複執行」裡就好，不用另外寫收訊息的程式；第一次讀的主題會自動訂閱。

## 注意

- **WiFi 密碼會寫在程式裡**：分享專案或範例前記得拿掉。
- **公開 broker 是大家共用的**：任何人都可能看到你送的資料、也可能送資料進來，不要傳敏感資料；想避免和別人的主題撞在一起，可以加前綴（例如 `myclass/team1`），儀表板也要用一樣的前綴。
- 主機用 MQTT 的 TCP 1883 連線（儀表板在瀏覽器裡用 WebSocket），連的是同一個 broker，所以可以互傳。
- 韌體有 `umqtt.simple` 就用韌體的；沒有的話用這個擴充附的一份（micropython-lib 的 umqtt.simple，MIT 授權）。
